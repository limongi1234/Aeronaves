# Jogo de Aeronaves

Jogo de nave em **HTML, CSS e JavaScript (jQuery)** desenvolvido a partir da aula "Construindo o seu primeiro jogo de naves" da DIO.

Em relação ao projeto da aula, fiz algumas alterações:

- os inimigos aumentam de velocidade de forma diferente ao longo da partida;
- aparecem vidas extras durante o jogo para recarregar a energia;
- a nave é controlada pelas setas direcionais.

## Como jogar

- **Seta para cima / seta para baixo**: mover a nave
- **D**: disparar
- Resgate os amigos e destrua os inimigos sem deixar a energia acabar.

## Como executar

Abra o arquivo `index.html` no navegador. Não há etapa de build.

## Tecnologias

- HTML e CSS
- JavaScript com jQuery e o plugin jQuery Collision
